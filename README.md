# Annieka-Jo-Obana
MOOD JOURNAL

Developer: Annieka Jo A. Obana

Section: BSINTE 2A

ABOUT THE PROJECT: This application is designed to help users track their daily moods and express their feelings through journaling.

Features:
Users can select their current mood.
Users can write about their feelings and daily experiences.
Users can save their journal entries.
Users can review their previous moods and entries.
